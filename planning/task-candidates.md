## Cheap initial matrix

Start with actor proposals and inventory: these avoid renderer startup and give exact, cheap acceptance signals. Include withheld mirrored positions, new IDs, malformed JSON, duplicate keys, unsupported actions, stale scene revisions and repeated invalid proposals. Freeze acceptance before running adaptation. Include ordinary valid cases so a harness that rejects everything cannot win.

Stage flat-avatar commands only after offline contracts pass. A compact custom harness can invoke the same narrow control adapter; it need not reproduce Hermes's entire integration catalog. Runtime adoption still requires isolation, cancellation, reconnect and visible-output checks.

A result in Hermes is a task-selection signal, not evidence that a smaller model or a different harness will succeed. Keep transcript token counts separate from actual cost, prefill speed and decode speed.
