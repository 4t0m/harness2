# Next model trials

## Art-production manager

Provide the immutable brief revision and a compact job-plan schema. Ask for three silhouette-variation jobs with the known capability, finite budget metadata, no dependencies for parallel auditions, and pending status. Validate with JobBoard.from_plan. A valid plan proves only state/shape compliance: the model has not designed distinct silhouettes or generated images.

Then supply a host snapshot with one completed job, one failed and one pending. Ask for a single retry request referencing the failed job and a fresh ID. Trusted host code performs the transition. Assert that the completed receipt is byte-for-byte unchanged. Ask a deliberately invalid retry of a completed job and require a truthful rejection. Keep retries as operations, not wholesale ledger rewrites.

Creative direction quality needs a separate audition: three descriptions that actually differ along the requested axis, with preserved identity. Human review remains required; exact ID uniqueness is insufficient diversity evidence.
