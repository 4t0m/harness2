# Inspiration and experiments to extract

These public tweet references were located through the local archive. Treat their claims as leads, not verified software capability. No raw bookmark metadata or private annotations are copied here.

- https://x.com/ivy432hz/status/2108240644913447112 describes an avatar-like result made from H3 video, sampled frames and 2D morphing, with many base/eye images. Experiment idea: an authored pose atlas with separate eye layers, deterministic transition selection and small model semantic control. First gate: a small legally reusable test asset, not hundreds of generated frames. Measure popping, gaze consistency and interruption recovery separately.
- https://x.com/johnjnay/status/1645387785514172417 points toward agents with memory, reflection and planning. Experiment idea: compact scene/production ledger containing accepted decisions and unresolved tasks, rather than ever-growing transcript history. Test fresh-session recovery and stale-decision detection. This does not imply that open-ended autobiographical memory is necessary.
- https://x.com/simplifyinAI/status/2104216950260035980 promotes AIRI and avatar/provider integrations. Experiment idea: keep body runtime independent of inference so a small local model, hosted model and scripted controller can share the same typed action contract. Claimed provider/runtime capabilities need independent source/runtime verification before adopting them.

## Practical branches

1. Pose-atlas controller: select authored key poses and eye/mouth overlays with an explicit capability catalog.
2. Production ledger: job/revision state and brief constraints survive model reset.
3. Director audition task: request useful variation without changing fixed identity traits; compare context-conditioned variants while leaving human taste authority intact.
4. Adaptive scaffolding: use failed task patterns to improve validation hints or tool granularity; do not let adaptation change acceptance criteria.

New rendering work is deferred until the cheap task contracts and provider path are tested. No tweet is evidence that our current rig, H3 recipe or local model supports a feature.
