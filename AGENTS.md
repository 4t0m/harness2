# Harness² local-agent lab

Read planning/README.md before adding experiments. Preserve upstream implementation and history; put our planning in planning/ and small experiment extensions in clearly named modules. Use topic branches under codex/.

This repository owns custom harness and small-model experiments. Hermes remains the integration and established-baseline lane; character design stays with the character workshop. Transfer accepted task contracts and evidence, not credentials or entire conversation archives.

Default to deterministic CPU-only checks on the Mac. Model-backed experiments need explicit provider configuration and bounded calls/time; do not assume the ChatGPT subscription is an API credential. Do not invoke upstream benchmark setup, cloud services, broad shell agents or heavy rendering merely to test an adapter.

Keep authoritative scene facts and acceptance checks outside model-editable harness surfaces. Separate first-pass, repaired, timeout, unsupported and falsely claimed completion. Preserve source revisions, failed proposals and verification receipts. Never report scripted editor tests as model trials or structural correctness as visual acting quality.

Fine-tuning is a separate experimental axis from harness adaptation. Split by task family before curating training data. Do not publish private traces, credentials, model endpoints or personal assets.
